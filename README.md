# AI PDF Chatbot

An AI-powered PDF chatbot that allows users to upload PDF documents and ask questions about their content using OpenAI, LangChain, and FAISS.

## Features

- Upload PDF documents
- Extract and process text
- Ask natural language questions
- AI-powered answers using OpenAI
- Fast document retrieval with FAISS

## Tech Stack

- Python
- Streamlit
- LangChain
- OpenAI
- FAISS
- PyPDF
- Python-dotenv

## Installation

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run stpdf.py
```
